# The Helio 213
This is my original prototype for the **Helio** platform. It is... Bad. I did absolutely zero research whatsoever when developing it, I just arbitrarily came up with a platform and told an AI to implement it. I claim no rights to the code, and feel absolutely no pride in this version of the project. The only thing it really did for me is act as a platform on which to first start practicing assembly code. At the point of making this, I had no plans to turn it into a "real" project. In the new Helio 210 project, I don't think any of this old code was reused whatsoever. I did not use AI in the design or implementation of the new project either; this was always intended to be an educational project, so when I decided to start from scratch, the only proper choice was to write the entire project myself, line by line, reading how the original worked, trying to figure out why, then trying to figure out how to make it better. In all honesty, I kinda hate it. I only chose to upload it here for transparency and archival reasons.

Maybe I'll come back and write out a specsheet eventually, but other than that, this is a dead project I have no plan to return to. Peruse only if you are interested in comparing this to my newer project, please. I'm honestly mortified enough to know people are doing that...
